# 🗳️ UP वोटर लिस्ट PDF → Excel AI कनवर्टर (Local AI)

उत्तर प्रदेश निर्वाचन आयोग (Electoral Roll / Voter List) की PDF फाइलों को **Excel (.xlsx)** में बदलने वाला 100% स्थानीय AI ऐप।

---

## ✨ मुख्य विशेषताएँ (Key Features)

- 🚀 **100% लोकल AI**: किसी बाहरी Cloud API या इंटरनेट कनेक्शन की आवश्यकता नहीं।
- 🏛️ **उत्तर प्रदेश विशिष्ट**: UP के 3-कॉलम और 2-कॉलम ग्रिड लेआउट और देवनागरी हिंदी टेक्स्ट के लिए विशेष रूप से डिज़ाइन।
- 📊 **सुंदर व संपूर्ण Excel शीट**:
  - **शीट 1 (मतदाता सूची)**: क्र.सं., मतदाता का नाम, सम्बन्ध, पिता/पति का नाम, मकान सं., आयु, लिंग, EPIC नं. (Voter ID), विधान सभा, भाग सं., पेज सं.
  - **शीट 2 (सांख्यिकी व सारांश)**: कुल मतदाता, पुरुष/महिला संख्या, लिंगानुपात, आयु-वर्ग वार वर्गीकरण (18-25, 26-40, आदि)।
- 👁️ **लाइव प्रिव्यू व इन-लाइन संपादन**: डेटा टेबल में सीधे किसी भी रिकॉर्ड को क्लिक करके सुधारें।
- 🔍 **स्मार्ट सर्च व फ़िल्टर**: नाम, पिता का नाम, मकान नंबर या EPIC नंबर से तुरंत खोजें।
- ⚡ **1-क्लिक सैंपल डेमो**: बिना अपनी फ़ाइल अपलोड किए तुरंत लखनऊ विधान सभा (AC-174) के 60 मतदाताओं के सैंपल से टेस्ट करें।

## 🚀 कैसे चलाएँ (How to Run)

### तरीक़ा 1: सीधे `run.bat` चलाएँ
फ़ोल्डर में स्थित `run.bat` पर डबल-क्लिक करें। यह स्वचालित रूप से सर्वर शुरू करके ब्राउज़र में ऐप खोल देगा।

### तरीक़ा 2: टर्मिनल/PowerShell से
```bash
cd "C:\Users\HP\.gemini\antigravity-ide\scratch\voter-list-converter"
& ".venv\Scripts\python.exe" -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```
फिर ब्राउज़र में खोलें: **`http://localhost:8000`**
